# 0001. Package name and home

- Status: Accepted
- Date: 2026-11-09
- Deciders: Simon Vestergaard Laursen

## Context

The plugin needs a name for npm and the repository before any code is written.

## Decision

The package and repository are named **`cap-okf`**.

## Consequences

Install command is `npm add -D cap-okf`. A move under a CAP community organisation later would be a rename handled by a new ADR.
